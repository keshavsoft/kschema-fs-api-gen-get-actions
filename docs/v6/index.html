⚙️ How It Works 💡 Why Use This Repo

Repository: KSCHEMA-FS-API-GEN-GET-ACTIONS

This repository automates the generation of GET methods for API endpoints. The latest version (v6) inside the test folder demonstrates how each GET action works: distinct, find, firstRecord, lastRecord, and showAll.

Step-by-Step Execution Guide

  1. Install Dependencies: 
    npm install
  2. Run a Test Script: For example, test/v6/ShowAll/test.js: 
    import path from "path";
import { showAll } from "../../../index.js";

showAll({
  toPath: process.cwd(),
  showLog: true,
  inGenerateRest: true
});
  3. Verify Generated Files: After execution, new JS files are created that interact with your data layer.

Available GET Methods

  • distinct → Returns unique values from a dataset.
  • find → Retrieves records matching a query.
  • firstRecord → Fetches the first record in a dataset.
  • lastRecord → Fetches the last record in a dataset.
  • showAll → Displays all records, with optional REST generation.

Configuration Note: Each method accepts parameters like toPath, showLog, and inGenerateRest to control output location, logging, and REST scaffolding.
